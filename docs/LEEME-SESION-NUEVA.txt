5. LO QUE HAY QUE REINSTALAR PARA TRABAJAR
--------------------------------------------------------------------------------

El truco necesita esto. Sin Rust no compila nada.

  rustup            https://rustup.rs  (o winget install Rustlang.Rustup)
  target wasm32     rustup target add wasm32-unknown-unknown
  wasm-bindgen      la version tiene que COINCIDIR con el crate en Cargo.lock.
                    Antes de instalar, leela:

                        Select-String -Path Cargo.lock -Pattern '^name = "wasm-bindgen"$' -Context 0,2

                    Sola que se va por cargo install:

                        cargo install wasm-bindgen-cli --version <esa> --locked

                    Si la version NO coincide, el .wasm se genera bien y el fallo
                    aparece en RUNTIME, en un telefono, no en el build. Es el
                    error mas caro de este proyecto.

  Node              20 o mas. En la maquina anterior era v24.15.0
  git               y las credenciales de GitHub: gh auth login

VERIFICACION TRAS INSTALAR:

  rustc --version
  rustup target list --installed
  wasm-bindgen --version      tiene que coincidir con Cargo.lock
  node --version
  gh auth status
